# mayhen-admin

## Applicable Paths
`resources/views/admin/, public/assets/admin/, app/Http/Controllers/Admin/`

## Purpose
Build an independent, efficient Admin dashboard without third-party admin kits.

## Mandatory Rules
- Admin assets live in public/assets/admin/ with mayhen_admin_ prefix.
- Complete separation from Client layouts and stylesheets.
- Comprehensive audit logging for sensitive actions (price changes, status updates, user blocks).

## Definition of Done
- Verified against Master Prompt requirements.
- Code is clean, well-documented, tested, and formatted.
