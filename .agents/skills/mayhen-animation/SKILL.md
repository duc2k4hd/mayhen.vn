# mayhen-animation

## Applicable Paths
`public/assets/client/css/invitations/, public/assets/client/js/invitations/`

## Purpose
Design captivating, purposeful wedding invitation motions.

## Mandatory Rules
- Core templates: Envelope Reveal, Paper Unfold, Silk Curtain, Editorial Scroll, Minimal Luxury.
- Prioritize GPU acceleration: transform, opacity, will-change.
- Never block reading or interaction; allow skipping animations.
- Respect @media (prefers-reduced-motion: reduce).

## Definition of Done
- Verified against Master Prompt requirements.
- Code is clean, well-documented, tested, and formatted.
