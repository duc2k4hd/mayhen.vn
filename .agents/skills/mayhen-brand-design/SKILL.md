# mayhen-brand-design

## Applicable Paths
`public/assets/client/css/common/tokens.css, docs/design/`

## Purpose
Establish the Quiet Luxury, Minimal, Romantic brand identity of May Hen.

## Mandatory Rules
- Color Palette: Ivory White (#FCFBF9), Warm Cream (#F7F4EE), Soft Beige (#EFE9E0), Charcoal (#1A1A1A), Muted Gold (#C5A880), Dusty Rose (#D4A5A5), Sage Green (#9FAF90).
- Typography: Elegant Serif for Headings (Playfair Display / Cormorant Garamond), Modern Sans-Serif for Body (Inter / Be Vietnam Pro), Delicate Script for accents only.
- No flashy gradients or loud commercial e-commerce aesthetics.

## Definition of Done
- Verified against Master Prompt requirements.
- Code is clean, well-documented, tested, and formatted.
