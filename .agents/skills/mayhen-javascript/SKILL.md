# mayhen-javascript

## Applicable Paths
`public/assets/client/js/, public/assets/admin/js/`

## Purpose
Vanilla JavaScript without Vue, React, Alpine.js, jQuery, GSAP, or Swiper.

## Mandatory Rules
- Use Native ES Modules (import/export), Fetch API, IntersectionObserver, ResizeObserver.
- Target elements using data-mayhen-* attributes rather than styling classes where appropriate.
- Handle errors cleanly; no memory leaks; clean up event listeners.
- No eval, no direct unsanitized innerHTML assignment.

## Definition of Done
- Verified against Master Prompt requirements.
- Code is clean, well-documented, tested, and formatted.
