# mayhen-ui-ux

## Applicable Paths
`resources/views/client/, public/assets/client/`

## Purpose
Ensure sublime UI/UX on mobile devices and desktops.

## Mandatory Rules
- Mobile-first approach: test on 360px, 375px, 390px, 414px, 430px.
- Minimum touch target 44x44px for interactive elements.
- Proper contrast ratio (WCAG AA), accessible labels, keyboard focus visibility.
- Reduced-motion support via prefers-reduced-motion.

## Definition of Done
- Verified against Master Prompt requirements.
- Code is clean, well-documented, tested, and formatted.
